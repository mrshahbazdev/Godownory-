# Godownory

Offline warehouse/godown register — items with per-godown stock grid, goods in/out challans (3-part print: office/party/gate), godown-to-godown transfers, weighted-average cost + stock valuation, supplier & customer ledgers with WhatsApp reminders, low-stock alerts, receipts & payments. Encrypted local database, PIN roles, opt-in LAN sharing. No account, no internet.

## Dev
npm install && npm run dev

## Build (Windows .appx)
npm run dist:win

Set `build.appx.identityName` / `publisher` from Partner Center before building for the Store.
